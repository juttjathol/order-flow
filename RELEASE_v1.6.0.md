# Order Flow v1.6.0

## Features
- One license = one Main device (bound on first activation)
- SaaS: Reset device, Delete customer/key, +30 days, Trial keys, WhatsApp send
- Activity log, Expiring in 7 days, Light/Dark theme
- App: email signup, currency on menu, strict license bind
- Version 1.6.0+9

## Deploy
1. Push to main (Cloudflare Pages auto-deploys public + functions)
2. Tag: `git tag v1.6.0 && git push origin v1.6.0` for APK
